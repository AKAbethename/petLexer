# Компилятор. Лексер

### Исходный язык: C (ограниченный)
### Инструментальный язык: C++


## Рассматриваемые возможности языка C для лексера

**Типы**. Тип int, double. Указатели опускаются

**Идентификаторы**


**Операторы**. +, -, *, /, %, &&, ||, =, ==, >, <, >=, <=, !=

**Ключевые слова**. if, else, while, do, switch, case, break, return, sizeof, const, int, char

**Пунктуационные знаки**. {, }, [, ], (, ), ;, ,

## Описание работы компилятора

Компилятор принимает на вход файл .c, считывает код на языке C, и возвращает файл .txt, содержащий исходный код в виде последовательности токенов


*Замечание 1*. Лексический анализатор может удалять закомментированную часть кода.

*Замечание 2*. Лексический анализатор может отслеживать, под каким номером идет данная строка и сколько символов в данной строке.


## Заметки

1. Токены имеют не более одного значения атрибута. Для токена **id** этим атрибутом является указатель на запись в таблице; запись содержит информацию о типе, области видимости, месте первого нахождения[1].
